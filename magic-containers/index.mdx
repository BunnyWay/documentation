## What's included

- [Autoscaling](/magic-containers/autoscaling) adds replicas in a region when CPU usage climbs and removes them when it drops. [Autoprovisioning](/magic-containers/regions#autoprovisioning) follows your traffic and deploys to new regions as demand appears.
- Every app runs inside a [gVisor sandbox](/magic-containers/sandbox), which handles system calls in a user-space kernel so your code never reaches the host kernel directly.
- Expose your app through a [CDN endpoint](/magic-containers/endpoints#cdn) for HTTP traffic, or an [Anycast endpoint](/magic-containers/endpoints#anycast) for direct IP access.
- Attach [persistent volumes](/magic-containers/persistent-volumes) to keep data across restarts and redeploys.
- Private images work once you [connect your Docker Hub or GitHub registry](/magic-containers/image-registries).
