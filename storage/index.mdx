![bunny.net Storage](/images/storage/storage.png)

Bunny Storage is object storage that keeps a copy of your files in each region you pick and serves them through Bunny CDN. Uploads land in your primary region and replicate on their own, and each request is answered by the copy closest to the CDN edge that asks for it.

<Card title="Storage Quickstart" icon="rocket" horizontal href="/storage/quickstart">
</Card>

## What's included

- **Global replication** to up to 15 regions, depending on the [storage tier](/storage/storage-tiers)
- **Nearest-region delivery**, so uncached requests come from the closest copy
- **Five ways to manage files**: the dashboard, the CLI, the HTTP API, the S3-compatible API, and FTP
- **Built-in CDN connection**, so any pull zone can use a storage zone as its origin
