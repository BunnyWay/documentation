VitePress builds your docs into `.vitepress/dist`, inside the folder that holds your content.

| Setting | Value |
| --- | --- |
| Build command | `npm run docs:build` |
| Output directory | `.vitepress/dist` |

## Configure VitePress

`npx vitepress init` names the build script `docs:build`, but the CLI runs `build`. Set the build command in `bunny.jsonc` at your project root. The CLI also expects `.vitepress` at the project root, so if your docs live in a `docs` folder, set the output directory too:

```jsonc bunny.jsonc
{
  "sites": {
    "build": "npm run docs:build",
    "dir": "docs/.vitepress/dist"
  }
}
```

Leave `cleanUrls` off. With it on, VitePress writes `about.html` and links to `/about`, which returns a 404.
