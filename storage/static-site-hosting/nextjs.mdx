Next.js can export your app as static HTML, CSS, and JavaScript into `out`.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `out` |

## Configure Next.js

Turn on static export in `next.config.ts`, and write each page as a folder with an `index.html`. On an older project, the same options go in `next.config.js` or `next.config.mjs`:

```ts next.config.ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  output: "export",
  trailingSlash: true,
  images: { unoptimized: true },
};

export default nextConfig;
```

Without `trailingSlash`, Next.js writes `/about` as `about.html`, and a request for `/about` returns a 404.

`images.unoptimized` lets `next/image` work without the image optimisation server, which a static export doesn't have. A static export also can't use other features that need a server, such as API routes. See the [Next.js static exports guide](https://nextjs.org/docs/app/guides/static-exports) for the full list. To run Next.js with a server, deploy it with [Magic Containers](/magic-containers/guides/nextjs).
