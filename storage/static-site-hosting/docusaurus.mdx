Docusaurus builds a static HTML page for every doc and blog post into `build`.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `build` |

## Configure Docusaurus

Set `url` and `baseUrl` in `docusaurus.config.js` to match where the site is served, for example `url: "https://docs.example.com"` and `baseUrl: "/"`. Leave `trailingSlash` unset, or set it to `true`. With `false`, Docusaurus writes `about.html` and links to `/about`, which returns a 404.
