Jekyll writes your site to `_site`. The CLI detects Jekyll from your `Gemfile` or `_config.yml`, and runs the build through Bundler.

| Setting | Value |
| --- | --- |
| Build command | `bundle exec jekyll build` |
| Output directory | `_site` |
