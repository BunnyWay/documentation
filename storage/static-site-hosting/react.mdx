Create a React app with Vite by running `npm create vite@latest my-app -- --template react`. Vite builds your app into `dist`, and the Bunny CLI detects it as a Vite project. If you use React Router in framework mode, follow the [React Router guide](/storage/static-site-hosting/react-router). For Next.js, follow the [Next.js guide](/storage/static-site-hosting/nextjs).

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `dist` |

## Configure React

If you use React Router, `createBrowserRouter()` gives you clean URLs such as `/about`. Those need the client-side routing fallback described below. `createHashRouter()` works without it.
