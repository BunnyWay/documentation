Any React build that produces static files runs on Bunny Storage. This page covers the React-specific parts. The deployment mechanics live in the [Bunny CLI](/storage/static-site-hosting/bunny-cli) and [manual setup](/storage/static-site-hosting/manual-setup) guides.

## Build

```bash
npm run build
```

| Setup                    | Output folder |
| ------------------------ | ------------- |
| Vite                     | `dist`        |
| Create React App         | `build`       |
| React Router (framework) | `build/client` |
| Next.js static export    | `out`         |

## Deploy

<Tabs>
  <Tab title="Bunny CLI">
    ```bash
    bunny sites create my-react-app
    bunny sites deploy ./dist --build "npm run build" --production
    ```

    The CLI creates the Storage Zone and Pull Zone, uploads the build, and prints the live URL. See the [Bunny CLI guide](/storage/static-site-hosting/bunny-cli) for previews, rollbacks, and GitHub Actions.

  </Tab>
  <Tab title="Manual">
    Create a Storage Zone, upload the contents of your build folder to its root, and connect a Pull Zone. See [Manual setup](/storage/static-site-hosting/manual-setup) for the full walkthrough.
  </Tab>
</Tabs>

## Client-side routing

React Router resolves URLs in the browser. The first request for `/dashboard` still goes to the CDN, and nothing is stored at that path, so it returns a 404 unless you add a fallback.

Set the Storage Zone's **404 File path** to `/index.html` and enable **Rewrite 404 to 200 status code**, as described in [client-side routing](/storage/static-site-hosting/manual-setup#configure-client-side-routing). Missing paths then serve your app shell and the router takes over.

<Warning>
  Without this, refreshing on `/dashboard` or opening a shared link to
  `/users/123` returns a 404.
</Warning>

Pre-rendered React output, such as a Next.js static export, writes an HTML file per route and needs no fallback.

## Environment variables

React apps read configuration that's embedded at build time:

<Tabs>
  <Tab title="Vite">
    ```bash .env.production
    VITE_API_URL=https://api.example.com
    ```

    ```js
    const apiUrl = import.meta.env.VITE_API_URL;
    ```

  </Tab>
  <Tab title="Create React App">
    ```bash .env.production
    REACT_APP_API_URL=https://api.example.com
    ```

    ```js
    const apiUrl = process.env.REACT_APP_API_URL;
    ```

  </Tab>
</Tabs>

The values end up in the bundle, so they're public and they only change when you rebuild. Keep API keys and other secrets on a server, or in an [Edge Script](/scripting).

## Caching

Modern React builds hash asset filenames, such as `main.a1b2c3.js`, so those files can cache for a year. Keep `index.html` on a short cache time, because it's the file that points at each new build's assets. See [cache configuration](/storage/static-site-hosting#cache-configuration).
