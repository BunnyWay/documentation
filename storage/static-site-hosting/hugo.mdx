Hugo writes your site to `public`. The CLI detects Hugo from `hugo.toml` or `hugo.yaml`, or from a `config.toml` next to a `content` folder, and needs `hugo` installed to run the build.

| Setting | Value |
| --- | --- |
| Build command | `hugo --minify` |
| Output directory | `public` |

## Configure Hugo

Set `baseURL` in your Hugo config to the URL your site will be served from.
