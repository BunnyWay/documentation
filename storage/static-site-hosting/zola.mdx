Zola writes your site to `public`. The CLI detects Zola from a `config.toml` next to a `templates` folder, and needs `zola` installed to run the build.

| Setting | Value |
| --- | --- |
| Build command | `zola build` |
| Output directory | `public` |

## Configure Zola

Set `base_url` in `config.toml` to the URL your site will be served from.
