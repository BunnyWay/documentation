A standalone Blazor WebAssembly app publishes as static files that run in the browser. Publishing to `bin/publish` puts the site in `bin/publish/wwwroot`, a path that doesn't change with your target framework.

| Setting | Value |
| --- | --- |
| Build command | `dotnet publish -c Release -o bin/publish` |
| Output directory | `bin/publish/wwwroot` |

The CLI detects Blazor WebAssembly from a `.csproj` at the project root that uses the `Microsoft.NET.Sdk.BlazorWebAssembly` SDK, and needs the .NET SDK installed to run the build. Server-hosted Blazor apps need a server, so deploy them with [Magic Containers](/magic-containers) instead.
