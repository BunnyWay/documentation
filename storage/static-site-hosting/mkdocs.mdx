`mkdocs build` turns your Markdown into a static site in `site`. The CLI detects MkDocs from `mkdocs.yml`, and needs `mkdocs` installed to run the build.

| Setting | Value |
| --- | --- |
| Build command | `mkdocs build` |
| Output directory | `site` |
