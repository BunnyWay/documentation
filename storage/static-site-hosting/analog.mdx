Analog is the full-stack meta-framework for Angular. With static output turned on, it prerenders your routes into `dist/analog/public`.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `dist/analog/public` |

## Configure Analog

Turn on static output and list the routes to prerender in `vite.config.ts`:

```ts vite.config.ts
import { defineConfig } from "vite";
import analog from "@analogjs/platform";

export default defineConfig({
  plugins: [
    analog({
      static: true,
      prerender: {
        routes: async () => ["/"],
      },
    }),
  ],
});
```
