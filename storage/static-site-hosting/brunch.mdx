Brunch compiles and bundles your assets into `public` with a production build.

<Warning>
  Brunch is no longer maintained, and the `brunch` package on npm now belongs
  to a new owner. Pin the last release, `brunch@4.0.2`, as a dev dependency so
  `npx brunch` runs your local copy:

  ```bash
  npm install -D brunch@4.0.2
  ```
</Warning>

| Setting | Value |
| --- | --- |
| Build command | `npx brunch build --production` |
| Output directory | `public` |
