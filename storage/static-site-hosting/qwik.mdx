Qwik City's static adapter prerenders your routes into `dist`.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `dist` |

## Configure Qwik

Add the static adapter:

```bash
npm run qwik add static
```

Then set `origin` in `adapters/static/vite.config.ts` to the URL your site will be served from.
