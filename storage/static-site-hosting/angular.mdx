The Angular application builder writes your app to `dist/<project>/browser`, where `<project>` is the name in `angular.json`.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `dist/<project>/browser` |

## Configure Angular

The Bunny CLI deploys `dist` for Angular by default. Point it at the `browser` folder in `bunny.jsonc` at your project root:

```jsonc bunny.jsonc
{
  "sites": {
    "dir": "dist/my-app/browser"
  }
}
```
