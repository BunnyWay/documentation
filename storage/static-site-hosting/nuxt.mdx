`nuxi generate` prerenders every route of your Nuxt app into `.output/public`. To run Nuxt with a server, deploy it with [Magic Containers](/magic-containers/guides/nuxt).

| Setting | Value |
| --- | --- |
| Build command | `npx nuxi generate` |
| Output directory | `.output/public` |
