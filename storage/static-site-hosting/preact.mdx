Create a Preact app by running `npm init preact`. It sets up Vite, which builds your app into `dist`, and the Bunny CLI detects it as a Vite project.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `dist` |

Older apps built with `preact-cli`, which is no longer developed, output to `build` instead.
