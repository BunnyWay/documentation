Create a Vue app by running `npm create vue@latest`. It sets up Vite, which builds your app into `dist`, and the Bunny CLI detects it as a Vite project.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `dist` |

Older apps built with Vue CLI, which is in maintenance mode, also output to `dist`, so the same steps apply.

## Configure Vue

If you use Vue Router, `createWebHistory()` gives you clean URLs such as `/about`. Those need the client-side routing fallback described below. `createWebHashHistory()` works without it.
