SvelteKit's static adapter prerenders your app into `build`.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `build` |

## Configure SvelteKit

Install the static adapter:

```bash
npm install -D @sveltejs/adapter-static
```

Use it in `svelte.config.js`:

```js svelte.config.js
import adapter from "@sveltejs/adapter-static";

/** @type {import('@sveltejs/kit').Config} */
const config = {
  kit: {
    adapter: adapter(),
  },
};

export default config;
```

Then prerender every page, and write each one as a folder with an `index.html`, in `src/routes/+layout.js`:

```js src/routes/+layout.js
export const prerender = true;
export const trailingSlash = "always";
```

Without `trailingSlash`, SvelteKit writes `/about` as `about.html`, and a request for `/about` returns a 404.
