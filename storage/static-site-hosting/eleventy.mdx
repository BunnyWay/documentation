Eleventy writes your site to `_site`.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `_site` |

## Configure Eleventy

The CLI runs your `build` script. Add one to `package.json` if your project doesn't have it:

```json package.json
{
  "scripts": {
    "build": "npx @11ty/eleventy"
  }
}
```
