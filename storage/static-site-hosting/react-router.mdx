React Router in framework mode can build a single-page app with no server. The browser build lands in `build/client`.

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `build/client` |

## Configure React Router

Turn off server rendering in `react-router.config.ts`:

```ts react-router.config.ts
import type { Config } from "@react-router/dev/config";

export default {
  ssr: false,
} satisfies Config;
```
