---
title: "Quickstart"
description: "Create a storage zone and upload your first file in minutes"
---

<Steps>
  <Step title="Create a storage zone">
    <Tabs>
      <Tab title="Dashboard">
        1. In the dashboard, click **Storage**, then **Add Storage Zone**.

           <Frame>
             ![Add Storage Zone](/images/storage/add-storage-zone.png)
           </Frame>

        2. Enter a name for your storage zone.
        3. Choose a storage tier, **Standard** or **Edge (SSD)**.
        4. Choose your main region. Standard zones can use any region, and Edge (SSD) zones use Frankfurt (DE).
        5. Add replication regions if you want copies closer to your users.
        6. Turn on **S3 Compatibility** if you want to use S3 tools and SDKs.
        7. Click **Add Storage Zone**.

        See [Storage tiers](/storage/storage-tiers) and [Replication](/storage/replication) for help choosing.
      </Tab>
      <Tab title="CLI">
        <Note>
          Don't have the CLI installed? See the [CLI quickstart](/cli/quickstart) to install and authenticate.
        </Note>

        Create a zone interactively:

        ```bash
        bunny storage zones create
        ```

        The CLI prompts for a name, tier, region, and S3 support, then offers to link the directory and save the credentials to `.env`.

        For a non-interactive run, pass the settings as flags. `--pull-zone` also creates a pull zone that serves the zone on the web:

        ```bash
        bunny storage zones create my-zone --region DE --pull-zone --link
        ```

        See [`bunny storage`](/cli/commands/storage) for every flag.
      </Tab>
      <Tab title="API">
        Send your [account API key](/api-reference/authentication) to the [Add Storage Zone](/api-reference/core/storage-zone/add-storage-zone) endpoint:

        ```bash
        curl -X POST https://api.bunny.net/storagezone \
          -H "AccessKey: your-api-key" \
          -H "Content-Type: application/json" \
          -d '{"Name": "my-zone", "Region": "DE", "ReplicationRegions": ["NY"]}'
        ```

        The response includes the zone's `Password`, which the next steps use.
      </Tab>
    </Tabs>

    The tier, main region, and S3 compatibility are set when you create the zone.
  </Step>
  <Step title="Get your credentials">
    Each storage zone has its own password for uploads. It's separate from your account API key.

    <Tabs>
      <Tab title="Dashboard">
        Open your storage zone and click **FTP & API Access**. Copy the **Username**, which is your zone name, and the **Password**.

        <Frame>
          ![FTP & API Access](/images/storage/storage-access-key.png)
        </Frame>
      </Tab>
      <Tab title="CLI">
        Save the zone name, password, and region to `.env`:

        ```bash
        bunny storage zones credentials my-zone --connection http --save-env
        ```
      </Tab>
      <Tab title="API">
        The `Password` field in the Add Storage Zone response is the zone password. [Get Storage Zone](/api-reference/core/storage-zone/get-storage-zone) returns it again later.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Upload your first file">
    <Tabs>
      <Tab title="Dashboard">
        Open your storage zone's **File manager**, click **Upload**, and choose a file.

        <Frame>
          ![Upload File or Folder](/images/storage/upload-file-or-folder.png)
        </Frame>
      </Tab>
      <Tab title="CLI">
        ```bash
        bunny storage files upload ./file.jpg --zone my-zone --to images/
        ```
      </Tab>
      <Tab title="API">
        ```bash
        curl -X PUT \
          https://storage.bunnycdn.com/my-zone/images/file.jpg \
          -H "AccessKey: your-storage-password" \
          --upload-file ./file.jpg
        ```

        Use the [endpoint for your zone's main region](/storage/http#storage-endpoints).
      </Tab>
      <Tab title="S3 (rclone)">
        <Note>
          Needs a storage zone with S3 compatibility.
        </Note>

        ```bash
        rclone config create bunny s3 \
          provider=Other \
          access_key_id=my-zone \
          secret_access_key=your-storage-password \
          endpoint=https://de-s3.storage.bunnycdn.com

        rclone copy ./file.jpg bunny:my-zone/images/
        ```
      </Tab>
      <Tab title="FTP">
        Connect any FTP client with these settings:

        - **Host**: `storage.bunnycdn.com`
        - **Port**: `21`
        - **Username**: your storage zone name
        - **Password**: your storage zone password
        - **Mode**: Passive
      </Tab>
    </Tabs>
  </Step>
  <Step title="Connect a pull zone">
    A pull zone serves your files on the web. If you created the zone with `--pull-zone`, it already has one.

    1. In the dashboard, go to **CDN** and select a pull zone, or create one.
    2. In the pull zone settings, go to **Origin**.
    3. Set **Origin Type** to **Storage Zone** and select your zone.
    4. Click **Save**.

    Your files are now available at the pull zone URL:

    ```text
    https://your-pull-zone.b-cdn.net/images/file.jpg
    ```
  </Step>
