---
title: Authentication
description: Learn how to authenticate requests to the bunny.net APIs.
---

Send your API key in the `AccessKey` header with every request.

```bash
curl --request GET \
  --url https://api.bunny.net/dnszone \
  --header 'AccessKey: YOUR_API_KEY'
```

## Find your API key

Your account has one API key, and it covers account-level work such as managing pull zones, DNS zones, and other resources. You can view it at any time in the [dashboard](https://dash.bunny.net) under **Account** > **API**.

<Note>
  We're working on scoped API keys. You'll be able to limit an API key to specific products and actions.
</Note>

## Product credentials

Some APIs expect a credential scoped to a single resource instead of your account API key:

| API | Credential |
| --- | --- |
| Bunny Stream | The [video library API key](/stream/authentication) |
| Bunny Storage | The [storage zone password](/storage/http) |
| Bunny Database | A [database auth token](/database/connect/authorization#access-tokens) |

Managing video libraries, storage zones, and databases themselves uses your account API key.

<Warning>
  Anyone holding your API key can act on your account. Keep it in a secret store or environment variable, and leave it out of client-side code and public
  repositories.
</Warning>
