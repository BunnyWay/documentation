title: Quickstart
description: Make your first API request to bunny.net in minutes.
---

This guide walks you through making your first API request to bunny.net.

<Steps>
  <Step title="Create a scoped API key">
    1. In the [bunny.net dashboard](https://dash.bunny.net), go to [Account > Scoped API keys](https://dash.bunny.net/account/scoped-api-keys) and click **Create API Key**.
    2. Name the key, such as `quickstart`, and pick when it expires.
    3. Turn on **Grant all permissions and resources**, so the key can call every endpoint that accepts scoped API keys while you explore.
    4. Click **Create API Key**, then copy the key. It's shown only once.

    [Team members](/account/team-management) can't turn on **Grant all permissions and resources**. Select the permissions for the endpoints you'll call instead, such as `PullZone.Read` for the request in the next step.

    <Warning>
    This key can manage and delete everything in your account. Keep it secret, and replace it with a narrower key before you use it in production.
    </Warning>

  </Step>

  <Step title="Make your first request">
    Use the following curl command to list your pull zones:

    ```bash
    curl --request GET \
      --url https://api.bunny.net/pullzone \
      --header 'AccessKey: YOUR_SCOPED_API_KEY' \
      --header 'Content-Type: application/json'
    ```

    Replace `YOUR_SCOPED_API_KEY` with the key you copied from the dashboard.

  </Step>

  <Step title="View the response">
    A successful response returns a list of your pull zones:

    ```json
    {
      "Items": [
        {
          "Id": 1234,
          "Name": "my-pull-zone",
          "OriginUrl": "https://example.com",
          "Enabled": true,
          "Hostnames": [
            {
              "Id": 5678,
              "Value": "my-pull-zone.b-cdn.net"
            }
          ]
        }
      ],
      "CurrentPage": 0,
      "TotalItems": 1,
      "HasMoreItems": false
    }
    ```

    If you don't have any pull zones yet, the `Items` array will be empty.

  </Step>

  <Step title="Integrate with other APIs">

  <Step title="Narrow your key's permissions">
    The key from the first step can do anything your account can. Once you know which endpoints your integration calls, replace it with a key that can only call those endpoints.

    1. Open each endpoint in the API reference and note the permissions it lists. For example, [List Pull Zones](/api-reference/core/pull-zone/list-pull-zones) accepts `PullZone.Read` or `PullZone.Update`.
    2. [Create a scoped API key](/account/scoped-api-keys#create-a-scoped-api-key) with those permissions, and leave **Grant all permissions and resources** off. Limit it to the resources and IP addresses your integration uses. List endpoints, like List Pull Zones, need access to all resources of that product.
    3. Use the new key in your integration, then delete the `quickstart` key.

    See [Scoped API keys](/api-reference/scoped-api-keys) for the full guide.

  </Step>
</Steps>
