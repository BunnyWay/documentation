The Database API manages your Bunny Database instances. Use it to create and delete databases, change their regions, generate access tokens, and read usage statistics.

To run SQL queries against a database, use the [SQL API](/database/connect/sql-api) instead.

## Base URL

```
https://api.bunny.net/database
```

## Authentication

Send your account API key in the `AccessKey` header:

```bash
curl --request GET \
  --url https://api.bunny.net/database/v3/databases \
  --header 'AccessKey: YOUR_API_KEY'
```

<Note>
  Find your API key in the [account
  settings](https://dash.bunny.net/account/settings) under **API Keys**.
</Note>
