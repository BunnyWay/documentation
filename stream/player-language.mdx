The UI language controls the text shown in the Bunny Stream player interface, such as the settings menu, control tooltips, and caption labels. You can set it in two ways:

- **Library default:** set `UILanguage` on the video library so every video in that library uses the same player language.
- **Per player:** add the `lang` query parameter to an embed or direct play URL to override the library default for that player only.

If neither is set, English (`en`) is used.

## Supported languages

Use the code in the **Code** column as the value of the `UILanguage` field or the `lang` query parameter.

| Language | Code | Language | Code |
| --- | --- | --- | --- |
| Arabic | `ar` | Macedonian | `mk` |
| Bulgarian | `bg` | Norwegian | `no` |
| Chinese | `cn` | Polish | `pl` |
| Czech | `cz` | Portuguese | `pt` |
| Danish | `dk` | Romanian | `ro` |
| Dutch | `nl` | Russian | `ru` |
| English (default) | `en` | Serbian | `rs` |
| Finnish | `fi` | Slovakian | `sk` |

<Warning>
  Several codes differ from the ISO 639-1 standard, always use the codes listed above.
</Warning>

## Set the library default

<Steps>
  <Step title="Get your API key and library ID">
    You need your account API key and the ID of the video library you want to update. To find your API key, go to **Account → API key** in the [bunny.net dashboard](https://dash.bunny.net/account/api-key).
  </Step>
  <Step title="Check which languages support player translation (optional)">
    Call [Get Languages](/api-reference/core/stream-video-library/get-languages) to retrieve the current list of languages. Only entries where `SupportPlayerTranslation` is `true` can be used as the player UI language. <br />Use each entry's `ShortCode` as the value.

    ```bash
    curl --request GET \
      --url https://api.bunny.net/videolibrary/languages \
      --header 'AccessKey: YOUR_API_KEY'
    ```

    ```json Example response item
    {
      "ShortCode": "de",
      "Name": "German",
      "SupportPlayerTranslation": true,
      "SupportTranscribing": true,
      "TranscribingAccuracy": 95
    }
    ```
  </Step>
  <Step title="Update the video library">
    Call [Update Video Library](/api-reference/core/stream-video-library/update-video-library) and set the `UILanguage` field to your chosen language code.

    <CodeGroup>

    ```bash cURL
    curl --request POST \
      --url https://api.bunny.net/videolibrary/{libraryId} \
      --header 'AccessKey: YOUR_API_KEY' \
      --header 'Content-Type: application/json' \
      --data '{
        "UILanguage": "de"
      }'
    ```

    ```javascript JavaScript
    const libraryId = 12345;
    
    const response = await fetch(`https://api.bunny.net/videolibrary/${libraryId}`, {
      method: "POST",
      headers: {
        AccessKey: "YOUR_API_KEY",
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ UILanguage: "de" }),
    });
    
    const library = await response.json();
    console.log(library.UILanguage); // "de"
    ```

    ```python Python
    import requests
    
    library_id = 12345
    
    response = requests.post(
        f"https://api.bunny.net/videolibrary/{library_id}",
        headers={
            "AccessKey": "YOUR_API_KEY",
            "Content-Type": "application/json",
        },
        json={"UILanguage": "de"},
    )
    
    print(response.json()["UILanguage"])  # "de"
    ```

    </CodeGroup>

    Only the fields you include in the request body are changed. All other library settings stay as they are.
  </Step>
  <Step title="Verify the change">
    A successful request returns `200` with the updated video library, where `UILanguage` shows the new value. Reload any page with an embedded player to see the translated interface.
  </Step>
</Steps>

<Tip>
  To switch back to the default, set `UILanguage` to `en`.
</Tip>

## Override per player with a query parameter

Add `lang` to an embed or direct play URL to set the player language for that player only. It overrides the library's `UILanguage` setting, and the library setting stays unchanged. This is useful on multilingual sites, where each page can load the player in the visitor's language.

<Tabs>
  <Tab title="Embed URL">
    ```text
    https://player.mediadelivery.net/embed/{video_library_id}/{video_id}?lang=de
    ```

    ```html
    <iframe
      src="https://player.mediadelivery.net/embed/{video_library_id}/{video_id}?lang=de"
      title="Video player"
      loading="lazy"
      style="display: block; width: 100%; height: auto; aspect-ratio: 16 / 9; border: 0;"
      allow="autoplay; encrypted-media; picture-in-picture; fullscreen"
      allowfullscreen>
    </iframe>
    ```
  </Tab>
  <Tab title="Direct play URL">
    ```text
    https://player.mediadelivery.net/play/{video_library_id}/{video_id}?lang=de
    ```
  </Tab>
</Tabs>

`lang` can be combined with other [player parameters](/stream/embedding#supported-parameters) using `&`. For example, to load the French interface with French captions turned on:

```text
https://player.mediadelivery.net/embed/{video_library_id}/{video_id}?lang=fr&captions=fr
```

<Note>
  If the library uses [embed view token authentication](/stream/token-authentication), keep the `token` and `expires` parameters in the URL and add `lang` alongside them.
</Note>
