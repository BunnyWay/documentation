Bunny Database is built on libSQL, a fork of SQLite. Every database runs the same SQLite 3.45.1 core and exposes the same set of extra modules, functions, and syntax on top of it. There is nothing to enable: everything in this section is available on every database and every connection, and nothing can be added or removed per database.

Anything that SQLite added after version 3.45 is not available. See [Core functions](/database/sql-extensions/core-functions#not-available) for the specifics.

## Connection functions

Two functions report on the current connection:

| Function                        | What it does                                                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `libsql_server_database_name()` | The name of the database the connection serves.                                                                     |
| `last_rows_affected()`          | Rows changed by the last statement on this connection. Returns 0 on a fresh connection or after a zero-row update. |

## Standard SQLite features

The standard SQLite 3.45 scalar, aggregate, window, and date and time functions are all available, along with `STRICT` tables, `RETURNING`, `UPSERT`, generated columns, and common table expressions. See [Core functions](/database/sql-extensions/core-functions) for the full list and what is missing.
