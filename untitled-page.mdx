The UI language controls the text shown in the Bunny Stream player interface, such as the settings menu, control tooltips, and caption labels. It is configured per video library, so every video in that library uses the same player language.

English (`en`) is used by default.

## Supported languages

Use the code in the **Code** column as the value of `UILanguage`.

| Language | Code | Language | Code |
| --- | --- | --- | --- |
| Arabic | `ar` | Macedonian | `mk` |
| Bulgarian | `bg` | Norwegian | `no` |
| Chinese | `cn` | Polish | `pl` |
| Czech | `cz` | Portuguese | `pt` |
| Danish | `dk` | Romanian | `ro` |
| Dutch | `nl` | Russian | `ru` |
| English (default) | `en` | Serbian | `rs` |
| Finnish | `fi` | Slovakian | `sk` |
| French | `fr` | Slovenian | `si` |
| German | `de` | Spanish | `es` |
| Greek | `gr` | Swedish | `se` |
| Hungarian | `hu` | Thai | `th` |
| Indonesian | `id` | Turkish | `tr` |
| Italian | `it` | Ukrainian | `ua` |
| Japanese | `jp` | Vietnamese | `vn` |
| Korean | `kr` |  |  |

<Warning>
  Several codes differ from the ISO 639-1 standard, always use the codes listed above.
</Warning>

## Set the player UI language

<Steps>
  <Step title="Get your API key and library ID">
    You need your account API key and the ID of the video library you want to update. To find your API key, go to **Account → API key** in the [bunny.net dashboard](https://dash.bunny.net/account/api-key).
  </Step>
  <Step title="Check which languages support player translation (optional)">
    Call [Get Languages](/api-reference/core/stream-video-library/get-languages) to retrieve the current list of languages. Only entries where `SupportPlayerTranslation` is `true` can be used as the player UI language. Use each entry's `ShortCode` as the value.

    ```bash
    curl --request GET \
      --url https://api.bunny.net/videolibrary/languages \
      --header 'AccessKey: YOUR_API_KEY'
    ```

    ```json Example response item
    {
      "ShortCode": "de",
      "Name": "German",
      "SupportPlayerTranslation": true,
      "SupportTranscribing": true,
      "TranscribingAccuracy": 95
    }
    ```
  </Step>
  <Step title="Update the video library">
    Call [Update Video Library](/api-reference/core/stream-video-library/update-video-library) and set the `UILanguage` field to your chosen language code.

    <CodeGroup>

    ```bash cURL
    curl --request POST \
      --url https://api.bunny.net/videolibrary/{libraryId} \
      --header 'AccessKey: YOUR_API_KEY' \
      --header 'Content-Type: application/json' \
      --data '{
        "UILanguage": "de"
      }'
    ```

    ```javascript JavaScript
    const libraryId = 12345;
    
    const response = await fetch(`https://api.bunny.net/videolibrary/${libraryId}`, {
      method: "POST",
      headers: {
        AccessKey: "YOUR_API_KEY",
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ UILanguage: "de" }),
    });
    
    const library = await response.json();
    console.log(library.UILanguage); // "de"
    ```

    ```python Python
    import requests
    
    library_id = 12345
    
    response = requests.post(
        f"https://api.bunny.net/videolibrary/{library_id}",
        headers={
            "AccessKey": "YOUR_API_KEY",
            "Content-Type": "application/json",
        },
        json={"UILanguage": "de"},
    )
    
    print(response.json()["UILanguage"])  # "de"
    ```

    </CodeGroup>

    Only the fields you include in the request body are changed. All other library settings stay as they are.
  </Step>
  <Step title="Verify the change">
    A successful request returns `200` with the updated video library, where `UILanguage` shows the new value. Reload any page with an embedded player to see the translated interface.
  </Step>
</Steps>

<Tip>
  To switch back to the default, set `UILanguage` to `en`.
</Tip>
